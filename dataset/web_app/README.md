# 岗位技能演化 Web 控制台

Web 控制台是公司岗位和政府技术岗位的统一操作入口。页面顶部可切换岗位数据域；首页还可以选择当前查看的 CSV 数据源。选择后，首页概览、时序分析和人工优化会基于同一份数据展示，数据流测试页仍保留自己的 run 选择逻辑。

## 启动

在 Windows PowerShell 中：

```powershell
cd "C:\Users\lihaoyang\Desktop\挑战杯\共创\dataset\web_app"
python -m uvicorn backend.app:app --host 127.0.0.1 --port 8787
```

或：

```powershell
npm run web:job-update
```

打开：`http://127.0.0.1:8787`

请在 `dataset/.env` 中配置 LLM API Key。首次处理 JD 时，`text2vec` 模型可能需要下载。

## 页面能力

| 页面 | 功能 |
| --- | --- |
| 首页概览 | 当前月份、岗位数、技能数、待审核数、时序概览，以及全局 CSV 数据源选择 |
| 单条 JD 更新 | 输入岗位名、职责和要求，选择自动或人工确认模式 |
| 待审核队列 | 查看岗位候选、技能候选并决定是否入库 |
| 时序分析 | 按首页所选 CSV 查看技能频率、生命周期、迁移路径和岗位画像版本对比 |
| 人工优化 | 按首页所选 CSV 查看当前岗位画像；正式基础库支持保存人工覆盖 |
| 数据流测试 | 调用公司基线数据流的分析和比对功能 |

## 单条 JD 的两种模式

### 自动模式

系统执行标题清洗、text2vec Top-K、必要时 LLM 二次裁决和技能抽取。确认属于既有标准岗位时，直接写入当前数据源的事件流、频率表、技能池、时序产物和 SQLite。

### 人工确认模式

系统先完成完整推理，但不写入正式基础数据。页面展示：

- 原始标题和清洗后的标题。
- 岗位大族与标准岗位 Top-K、相似度和二次裁决建议。
- 抽取出的 `normalized_skill`、`kg_display_skill`、置信度和新技能提示。
- 用户可选择一个 Top-K 标准岗位，删除或改写技能，或手动补充规范技能。

确认“按所选岗位入库”后，才更新该数据源的正式 CSV 与 SQLite。确认新岗位只创建词典维护建议，不直接写入正式词典。

## 首页 CSV 数据源选择

首页“当前查看 CSV”提供统一数据源入口：

- `base`：当前岗位数据域的正式基础库。
- `test_stream:*`：测试专用 JD 数据流，当前包含 `large_test_20260807_19_23_per_job_month`。
- `run:*`：岗位数据流生成与评测系统历史 run 中可被识别的事件流。

切换后，以下页面会跟随刷新并显示当前选择文件：

- 首页概览。
- 时序分析。
- 人工优化。
- 单条 JD 更新页会显示当前查看文件提示，但单条 JD 入库仍写入当前岗位数据域的正式基础库。

数据流测试页不使用这个全局选择器，它继续通过“已有 run”选择自己的测试对象。

## 人工优化的落盘规则

“人工优化”保存到当前数据源 SQLite 的 `job_profile_manual_overrides` 表。它覆盖当前画像展示，但不篡改历史 JD、事件流、频率表或画像快照；因此人工判断和原始事实可分别追溯。

当前实现中，只有正式基础库会叠加 SQLite 人工覆盖层。测试数据源用于查看和分析，不建议把人工优化作为正式结果保存到测试数据流。

## 通过 Web 修改数据的规则

- 单条 JD 自动入库或人工确认入库后，系统自动更新对应数据域的事件流、频率、技能池、生命周期、迁移、画像和 SQLite。
- “人工优化”保存的是 SQLite 人工覆盖记录，不会直接编辑画像 CSV，也不会改写历史数据。
- 新岗位、新技能的确认会形成待维护建议；正式岗位词典和技能词典仍应由维护人员在 CSV 中审核修改后，再重新处理相关 JD。
- 不要用 Excel 直接改 Web 展示的频率、技能池或画像 CSV；这会绕过数据库和时序重算流程。

## 数据源对应关系

| Web 数据源 | 基础目录 | 数据库 |
| --- | --- | --- |
| 公司岗位 | `job_update/company_job_update/data/versions/<selected_version>/` | `job_update.db` |
| 政府技术岗位 | `job_update/government_job_update/data/base/` | `government_job_update.db` |

公司大流生成与评测数据目录：

```text
岗位数据流生成与评测系统/outputs/company_large_v2/
```

该目录是上游生成和评测数据，不是 Web 的正式运行数据源。

## 停止服务

在运行 Web 服务的 PowerShell 窗口按 `Ctrl+C`。服务不会自动在后台启动。
