# 中文简历-岗位标注规范

## 标注对象

每条样本由一份脱敏简历和一个具体岗位 JD 组成。标注者只能根据给出的简历与 JD 判断，不查看系统最终分数。

## 相关性等级

| 标签 | 定义 |
| --- | --- |
| 3 | 高度匹配：核心技能和主要硬条件基本满足，可以优先推荐 |
| 2 | 基本匹配：岗位方向合适，存在少量能够补足的技能缺口 |
| 1 | 弱相关：方向相近，但缺少关键技能或重要条件 |
| 0 | 不相关：岗位方向明显不符，或关键硬条件不满足 |

## 必填字段

- `resume_id`：简历标识。
- `job_id`：岗位标识。
- `relevance_grade`：0-3。
- `hard_constraint_pass`：`true`、`false` 或 `uncertain`。
- `matched_skills`：简历中明确具备且岗位需要的技能。
- `missing_required_skills`：岗位明确必需、简历未体现的技能。
- `missing_optional_skills`：岗位加分项中简历未体现的技能。
- `transferable_skills`：能够迁移到该岗位的相关技能。
- `resume_evidence`：支持判断的简历字段。
- `job_evidence`：支持判断的 JD 原文。
- `annotator_id`：匿名标注者编号。
- `notes`：无法归类的问题或不确定项。

## 判断顺序

1. 先检查学历、专业、经验等硬条件。
2. 再判断岗位方向和必备技能。
3. 然后判断加分技能、相邻技能和可迁移能力。
4. 最后给出整体相关性等级。

空白技能字段只能标记为“简历未体现”，不能断言候选人绝对不会该技能。

## 质量控制

- 每对简历-JD 由两人独立标注。
- 分歧由第三人仲裁。
- 使用加权 Cohen's Kappa 评估 0-3 等级一致性。
- 正式目标 Kappa 不低于 0.80。
- 银标和模型分数不得作为人工金标的直接依据。
